BigDFT-Suite tutorial

This branch is created to better understand how BigDFT works and how to generate an input file, run an optimization or a dynamic.
Much of the informations are comments in inputfiles or in scripts.

BigDFT and the Suite version needs to work at the best PyBigDFT. This program works as a Python api, it uses software and module contained in Suite to launch simulations and to visualize geometry input.
